# Replicate Frog
Replicate Frog is a Bot that automate Replicate simulations. Allowing for multiple simulations at once with different combinations.

# How Does It Work?
You write the elements you want to combine, each one in its respective side. Then, we send every possible combination between them to Replicate. and in a few minutes you receive a file with the results of the simulations.

# How Can I Use It?
• First, You go to the Actions tab, on the top of the page.
• Then, You click "Execute Frog" and "Run Workflow", a pop-up should appear next to the button.
• Then, you type the elements you want to combined, separating each one of them with equal signs. click "Run".
• Click on the three dots next to the Workflow in progress (With yellow spinning dot). if it doesn't appear, reaload the page.
• View the ... and click "run_script", wait for some minutes while the simulations are being prepared (you can click "Run Script" if you want more informations about the process).
• Wait until a check mark appears, meaning the file is ready to download at "....", at the bottom of the section. With that, the simulations are done.
