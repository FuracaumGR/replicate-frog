# Replicate Frog
Replicate Frog is a script that automate Replicate simulations. Allowing for multiple simulations at once with different combinations.<br>
<br>
![Frog](readmeimages/readmefrog.jpg)

## How Does It Work?
### test
You write the elements you want to combine, each one in its respective side. Then, we send every possible combination between them (ignoring elements within the same box) to Replicate. and in a few minutes you receive a file with the results of the simulations.

## How Can I Use It?
• First, you need to send me your username, via Discord DMs to @.furac, so you can be added as a Contributor<br>
• Once you're accepted, You go to the Actions tab, on the top of the page.<br>
• Then, You click "Execute Frog" and "Run Workflow", a pop-up should appear next to the button.<br>
• When it appears, you type the elements you want to combined, separating each one of them with equal signs. click "Run".<br>
• Click on the three dots next to the Workflow in progress (With yellow spinning dot). if it doesn't appear, reaload the page.<br>
• View the Workflow file and click "run_script", wait for some minutes while the simulations are being prepared (you can click "Run Script" if you want more informations about the process).<br>
• Wait until a check mark appears, meaning the file is ready to download at "Results", at the bottom of the section. With that, the simulations are done.
