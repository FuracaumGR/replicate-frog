# Replicate Frog
Replicate Frog is a script that automate Replicate simulations. Allowing for multiple simulations at once with different combinations.<br>
<br>
![Frog](readmeimages/readmefrog.jpg)

## How Does It Work?
You write the elements you want to combine, each one in its respective side. Then, we send every possible combination between them (ignoring elements within the same box) to Replicate. and in a few minutes you receive a file with the results of the simulations.

## How Can I Use It?
It's very simple and straight forwand, so a small list of steps should work.<br>

### Running the Script
Now that you're a Contributor, you should be able to run the script, being able to choose if you want to use the <em>Private Frog</em> or the <em>Public Frog</em> Here's a guide on how to use both versions.<br>

### Using Public Frog
The <em>Public Frog</em> allows for a faster and simpler usage of the script, but allows others to see what elements you combined and to download the <em>simulation-results.csv</em> file at the end. But if you don't mind privacy, you can follow these steps:<br>
<br>
• Firstly, go to the Actions tab, on the top of the page.<br>
• Then, click <em>Execute Public Frog</em> at the tab on the left and then click <em>Run Workflow</em>, a pop-up should appear next to the button.<br>
• When it appears, type the elements you want to combine in the categories <em>Elements A</em> and <em>Elements B</em>, separating each one of them with equal signs. Once you finished typing, click <em>Run</em>.<br>
• Click on the three dots next to the Workflow in progress (The Workflow with a yellow spinning dot). if it doesn't appear, reaload the page.<br>
• Click the button <em>View workflow file</em>. Once the page loads, click <em>run_script</em>, located at the tab on the left, wait for some minutes while the simulations are being prepared (you can check <em>Run Script</em> if you want more informations about the process).<br>
• Wait until a check mark appears, meaning the file is ready to download at <em>Results</em> at the bottom of the section. With that, the simulations are done. You can enjoy your file with all simulations LLaMa 2 cooked.<br>

### Using Private Frog
The <em>Private Frog</em> guide is very similar to the one made for <em>Public Frog</em>, but takes a bit more steps to set up. if you want privacy while simulating your recipes, that means, making so no one can see what elements you're using, and also keeping the file downloadable for only 1 minute, these are the following steps:

• Firstly, go to the Actions tab, on the top of the page. Just like the guide for <em>Public Frog</em>.<br>
• Then, you go to the website <em>https://dpaste.org</em> and write the elements you want to combine separated by equal signs, adding a newline to segregate them into 2 different categories, <em>Elements A</em> and <em>Elements B</em>.<br>
• On the top of the page, click on <em>Expire in one month</em> and set it to <em>One Time Snippet</em>.<br>
• Click on <em>Paste Snippet</em> and copy the link of the page.<br>
• Go back to <em>GitHub</em> and click <em>Execute Private Frog</em> at the tab on the left and then click <em>Run Workflow</em>, a pop-up should appear next to the button.<br>
• When it appears, paste the link and click <em>Run</em>. From now and on, everything is the same as if you were using the <em>Public Frog</em> option.<br>
• Click on the three dots next to the Workflow in progress (The Workflow with a yellow spinning dot). if it doesn't appear, reaload the page.<br>
• Click the button <em>View workflow file</em>. Once the page loads, click <em>run_script</em>, located at the tab on the left, wait for some minutes while the simulations are being prepared (Checking <em>Run Script</em> won't do much, but it's good if you want to ensure your dpaste link was deleted).<br>
• Wait until a check mark appears, meaning the file is ready to download at <em>Results</em> at the bottom of the section for 1 minute before being deleted permanently. With that, the simulations are done. You can enjoy your file with all simulations LLaMa 2 cooked.<br>
